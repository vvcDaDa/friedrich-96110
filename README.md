# 96110 夜班

> 《Friedrich 打工记》续作 · 一款关于反诈热线夜班接线员的中文网页小游戏

一年前，刚毕业的 Friedrich 从一笔 **¥1,200 的"点赞返利"** 开始，一步步掉进刷单骗局——卡单、补单、保证金、解冻金，一共被骗走 ¥17,525，打了 14 天工才还清网贷。

一年后，他成了 **96110 反诈热线** 的夜班接线员。电话那头，是正在被骗、还没转账的人。

## 玩法

7 个夜班，24 通电话。每通电话是一个回合制关卡：

| 数值 | 含义 |
|---|---|
| **信任度** | 来电者有多信任你。降到 0，对方认定你也是骗子，挂断。 |
| **施压度** | 骗子那边的催促。每回合自动上涨，到 100 时受害人完成转账。超过某条线时，对方可能先转出一笔。 |
| **剩余回合** | 通话时长上限。 |
| **劝阻进度** | 劝说成功的进度，填满即成功拦截。 |

每回合选一个行动：

- **提问**：问对了拿到线索（飞进右侧线索板）；问到冒犯的问题会掉信任。部分问题要先拿到某条线索才会出现。
- **判断**：选出诈骗类型。判断正确会解锁"针对性"劝说话术；判断错误信任大跌。**每晚都有一通"看起来很像诈骗"的真实电话**——把它当成诈骗就是"误判"。
- **劝说**：效果取决于判断是否正确，以及来电者的性格（每个人有喜欢和反感的说法，比如老人怕给子女添麻烦、学生在乎征信、恋爱中的人反感你否定对方）。
- **特殊行动**（每晚次数有限）：联系家属（需先问到联系方式）、紧急止付（需先拿到收款账户，能拦截/追回已转出的钱）、让对方挂掉另一部电话（施压度上涨减半）。

结局分档：**完全拦截 / 部分损失 / 被骗 / 误判**（真实来电的最佳结果是"正确放行"）。

白天：
1. **早间新闻 / 后续回访**：昨晚每通电话后来怎样了。
2. **线索墙**：散落在各通电话里的同一团伙的痕迹（相同的收款账户尾号、相同的话术、相同的 App……），把属于同一团伙的两张卡片连起来。每天可以试错 3 次。
3. **学一条新话术**：成长解锁，后面的夜班会用到。

第 7 夜，骗子团伙的"杰哥"亲自打进来冒充警察。你要一边拖住他，一边配合民警老陈定位。

### 结局

由 **挽回总金额、误判次数、是否破获团伙** 决定：

| 结局 | 条件（按顺序判定） |
|---|---|
| 「长夜有灯」（好） | 破获团伙（终局定位成功 且 线索墙关联 ≥ 5 条）+ 误判 ≤ 1 次 + 挽回 ≥ 60% |
| 「狼来了」 | 误判 ≥ 4 次 |
| 「电话还在响」（坏） | 挽回 < 50% |
| 「天快亮了」（普通） | 其余情况 |

另有 8 个成就（包括致敬第一作的「¥1,200」）。结局页附有反诈知识小结。

### 操作

- 数字键 **1–9** 选择行动和选项，**Esc / Backspace** 返回上一级。
- 旁白时 **点击 / 空格** 跳过打字效果；开场和夜班开场都可以跳过。
- **M** 或右上角按钮：一键开关全部声音。
- 手机竖屏可玩（宽 375px 起），线索板在右上角"🗂 线索"里。
- 每个回合、每通电话结束都自动存档，标题页可"继续游戏"。

## 本地运行

纯静态页面，没有构建步骤，没有依赖。

- **直接双击 `index.html`** 就能玩（所有脚本都是普通 `<script>`，不用 ES Module，`file://` 下也能运行）。
- 或者起一个静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

字体从 Google Fonts 加载（Noto Sans SC / Noto Serif SC），离线时自动退回系统字体。存档用 localStorage；浏览器禁用存储时游戏照常可玩，只是无法存档。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库，把本目录所有文件推上去（保留根目录的 `.nojekyll`）：

```bash
git init
```

```bash
git add . && git commit -m "96110 夜班"
```

```bash
git branch -M main && git remote add origin https://github.com/<你的用户名>/<仓库名>.git && git push -u origin main
```

2. 仓库 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、目录 `/ (root)`，保存。
3. 一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

所有资源路径都是相对路径，部署在子目录下也能正常工作。

### 新增一个案例

在 `js/cases.js` 里照着已有案例 `CASES.push({...})`，再把 `id` 加到 `js/story.js` 中对应夜晚的 `cases` 数组。字段含义见 `cases.js` 顶部注释。加完后跑一遍模拟，确认新案例有解、正确玩家能完全拦截：

```bash
node tools/simulate.js
```

（有无解关卡或正确玩家失败时，脚本以非 0 退出码结束；加 `--paths` 会打印每个案例的一条完全拦截路线。）

## 平衡模拟

`tools/simulate.js` 直接加载游戏里的 `engine.js`、`cases.js`、`story.js`，用同一套规则：

1. **穷举搜索**（记忆化 DFS）：验证每个案例都存在"完全拦截 / 正确放行"的路线。
2. **随机玩家**：每回合先随机选一类行动，再随机选一个选项。
3. **正确玩家**：每回合都做对的选择（先问关键线索 → 判断正确 → 特殊行动 → 最有效的劝说）。
4. **整局模拟**：不同水平的玩家打完 7 夜，统计结局分布。

最近一次结果（每个案例随机 4,000 次，整局各 1,000 局）：

- 24 / 24 个案例存在完全拦截路线，**没有无解关卡**
- 正确玩家完全拦截率 **100%**
- 随机玩家完全拦截率 **8.6%**（部分损失 13.6%，被骗 50.9%，误判 26.9%）

## 反诈知识（游戏里也有）

- **96110** 是反诈预警劝阻专线，接到请务必接听；拿不准也可以主动拨打咨询。
- 被骗后 **立刻拨打 110**，保留聊天记录、转账凭证、对方账号等证据。
- 公检法 **不会** 通过电话办案，**没有** "安全账户"。
- 正规客服 **不会** 让你开屏幕共享，**不会** 索要验证码。
- 所有刷单都是诈骗；不存在"注销校园贷"；追回被骗资金只能通过公安机关。
- **被骗不丢人。** 及时说出来、及时报警，才是最勇敢的。
